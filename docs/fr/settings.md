# Paramètres

| Paramètre | Description |
| --- | --- |
| Point de départ dans le menu | L'élément de menu affiché dans la barre de gauche ; ses sous-éléments apparaissent à droite. Champ obligatoire. Sélectionnez **Point de départ…** dans la liste — celle-ci affiche le menu sous forme d’arborescence en retrait, avec uniquement les éléments comportant des sous-éléments. Les éléments masqués dans le menu sont accompagnés de la mention « (masqué dans le menu) ». Si l’élément de menu ne figure pas dans la liste, sélectionnez **Saisir un autre ID de menu…** et saisissez l’adresse de sa page ou son ID à 24 caractères. |

L’ordre, le titre et la visibilité des entrées proviennent du menu de l’application
et y sont gérés, et non dans le widget.
