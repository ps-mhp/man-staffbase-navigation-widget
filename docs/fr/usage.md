# Étape par étape

Le point de départ est sélectionné dans la fenêtre **Sélectionner le point de départ**. Celle-ci s'ouvre
automatiquement dès que la boîte de dialogue des paramètres du widget apparaît ; une fois fermée,
le bouton **Sélectionner le point de départ** la rouvre.

À gauche se trouve le menu de l'application sous forme d'arborescence, surmonté d'un champ de recherche. Au centre
se trouvent le point de départ sélectionné et la barre telle qu’elle s’affiche.

## Insérer la navigation

1. Dans le menu de l’application, vérifiez quelle option de menu contient les pages souhaitées en tant que
   sous-rubriques. La navigation affiche toujours les sous-rubriques **d’une**
   rubrique de menu ; les pages doivent donc déjà figurer dans le menu sous celle-ci.
2. Ouvrez la page à modifier et placez le widget **Navigation** à l’
  emplacement souhaité, de préférence sur toute la largeur — la barre
  a besoin d’espace pour afficher les éléments côte à côte.
3. Dans la fenêtre de gauche, sous **Point de départ dans le menu**, cliquez sur l’option de menu
   dont vous souhaitez afficher les sous-options. La flèche devant un dossier permet
   de le déplier ; le champ de recherche situé au-dessus permet de trouver une option de menu par son titre.
   Seules les options de menu comportant des sous-options peuvent être sélectionnées.
4. En haut, au-dessus de **Ordinateur de bureau**, **Tablette** et **Mobile**, vérifiez que la barre s’adapte à la
   largeur de l’appareil.
5. Cliquez sur **Appliquer**, puis enregistrez la page. Sur la
   page : cliquer sur le titre ouvre la page, la flèche à côté affiche les
   sous-rubriques dans un menu déroulant.

Si la rubrique de menu ne figure pas dans l’arborescence :

1. Ouvrez la page de la rubrique de menu dans Staffbase et copiez l’**adresse complète**
   depuis la barre d’adresse.
2. Dans la fenêtre en bas à gauche, cliquez sur **Saisir l’ID ou l’adresse**.
3. Collez l’adresse dans le champ et cliquez sur **Définir comme point de départ**.
   Le widget récupère automatiquement l’ID. Le point de départ apparaît alors
   tout en haut de l’arborescence.

## Modifier le point de départ

1. Ouvrez les paramètres du widget — la fenêtre **Sélectionner le point de départ**
   s’ouvre avec le point de départ actuel sélectionné.
2. Cliquez sur un autre élément de menu à gauche.
3. Cliquez sur **Appliquer** et enregistrez. La barre affiche alors le nouveau
   point de départ et ses sous-éléments.

## Ajouter, supprimer ou réorganiser des entrées

Cette opération ne s’effectue pas dans le widget, mais dans le **menu** de l’application :

1. Ouvrez la gestion des menus dans Staffbase.
2. Faites glisser les pages sous le point de départ, supprimez-les ou réorganisez-les.
3. Rechargez la page contenant la navigation — la modification est immédiatement visible.

## Si quelque chose ne fonctionne pas

1. Si le menu ne se charge pas dans la fenêtre, cliquez sur **Réessayer**. Si cela
   ne fonctionne pas, saisissez le point de départ via **Saisir l’ID ou l’adresse**.
2. Si le message « Le menu n'a pas pu être chargé » s'affiche, cliquez sur
   **Réessayer** — dans la barre, comme dans un menu déroulant. Si
   cela ne fonctionne pas, vérifiez si l'élément d'entrée existe toujours dans le menu et,
   le cas échéant, sélectionnez-le à nouveau.
3. Si une entrée manque, vérifiez dans le menu si elle est réglée sur « Non visible » ou
   si la personne qui consulte la page est autorisée à la voir.
