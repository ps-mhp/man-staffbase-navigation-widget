# Étape par étape

## Insérer une navigation

1. Dans le menu de l'application, vérifiez quelle option de menu contient les pages souhaitées en tant que
   sous-rubriques. La navigation affiche toujours les sous-rubriques **d'une**
   option de menu ; les pages doivent donc déjà figurer dans le menu sous cette option.
2. Ouvrez la page à modifier et placez le widget **Navigation** à l’
  emplacement souhaité, de préférence sur toute la largeur — la barre
   a besoin d’espace pour afficher les éléments côte à côte.
3. Dans les paramètres, sous **Point de départ dans le menu**, ouvrez la liste
   **Sélectionner le point de départ…**. Elle affiche le menu sous forme d’arborescence
   indentée ; seuls les éléments de menu comportant des sous-éléments sont proposés.
4. Sélectionnez l’élément de menu dont vous souhaitez afficher les sous-éléments.
5. Enregistrez et vérifiez dans l’aperçu : cliquer sur le titre ouvre la page,
   la flèche ouvre les sous-rubriques sous forme de menu déroulant.

Si l’option de menu ne figure pas dans la liste :

1. Ouvrez la page de l’option de menu dans Staffbase et **copiez l’adresse complète**
   à partir de la barre d’adresse.
2. Dans la liste, sélectionnez **Saisir un autre ID de menu…**.
3. Collez l’adresse dans le champ. Le widget extrait lui-même
   l’ID.

## Modifier le point de départ

1. Ouvrez les paramètres du widget.
2. Sous **Point de départ dans le menu**, sélectionnez un autre élément de menu.
3. Enregistrez. La barre affiche alors le nouveau point de départ et ses
   sous-rubriques.

## Ajouter, supprimer ou réorganiser des entrées

Cette opération ne s’effectue pas dans le widget, mais dans le **menu** de l’application :

1. Dans Staffbase, ouvrez la gestion des menus.
2. Faites glisser les pages sous le point de départ, supprimez-les ou réorganisez-les.
3. Rechargez la page avec la navigation — la modification est immédiatement visible.

## Si quelque chose ne fonctionne pas

1. Si le message « Le menu n’a pas pu être chargé. » s’affiche, cliquez sur
   **Réessayer** — dans la barre comme dans un menu déroulant. Si cela ne fonctionne pas, vérifiez si le point de départ
   existe toujours dans le menu et, le cas échéant, sélectionnez-le à nouveau.
2. Si une entrée manque, vérifiez dans le menu si elle est réglée sur « Non visible » ou
   si la personne qui consulte le menu est autorisée à la voir.
