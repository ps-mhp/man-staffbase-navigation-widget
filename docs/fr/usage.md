# Pas à pas

## Insérer navigation

1. Vérifiez le menu de l’application pour voir quel élément contient les pages souhaitées comme
   sous-éléments. La navigation affiche toujours les sous-éléments **un** 
   Élément du menu ; donc les pages doivent déjà être suspendues en dessous dans le menu. 
2. Ouvrir la page pour l’édition et joindre le widget **Navigation** au
   , par exemple dans une colonne étroite à côté du texte. 
3. Dans les paramètres sous **Point de démarrage dans le menu** la liste
   **Sélectionnez le point de départ...** ouvrez-vous. Le menu affiche comme un indenté
   arbre ; seuls les éléments du menu comportant des sous-éléments sont proposés. 
4. Sélectionnez l’élément du menu dont les sous-éléments doivent apparaître. 
5. En option, entrez votre propre titre sous **Titre**, par exemple 
   « Liens supplémentaires ». Le titre du point de départ reste vide. 
6. Enregistrer et vérifier en aperçu : cliquer sur le titre ouvre la page, 
   La flèche descend d’un niveau. 

Si l’élément du menu n’est pas dans la liste : 

1. Ouvrez la page de l’élément du menu dans Staffbase et entrez l'**adresse complète** 
   De la barre d’adresses. 
2. Dans la liste, sélectionnez **Entrer un identifiant de menu différent...**. 
3. Collez l’adresse dans le champ. Le widget lit l’ID lui-même
   . 

## Changer de point de départ ou de cap

1. Ouvrez les paramètres du widget. 
2. Sous **Démarrer l’élément dans le menu**, sélectionnez un autre élément du menu ou sous
   **Titre** changer le texte. 
3. Sauvegarder. La navigation recommencera alors au premier niveau. 

## Ajouter, retirer ou réorganiser les entrées

Cela ne se fait pas dans le widget, mais dans le **menu** de l’application : 

1. Ouvrir la gestion du menu dans Staffbase. 
2. Glisser, retirer ou réordonner les pages sous le point de départ. 
3. Rechargez la page avec la navigation — le changement sera visible immédiatement. 

## Quand quelque chose ne marche pas

1. Si « Le menu n’a pas pu être chargé » apparaît, cliquez
   **Réessayer**. Si ça ne suffit pas, vérifie si le point de départ est
   Il existe toujours dans le menu, et si nécessaire, sélectionne-le à nouveau. 
2. Si une entrée manque, vérifiez dans le menu si elle est réglée sur « Non visible » ou
   si la personne qui lit a le droit de le voir.
