# Navigation

La navigation affiche un extrait du menu Staffbase sur une page :
Sélectionnez un élément du menu comme point de départ, et le widget affiche son
Sous-éléments en tant que liste. Si un sous-élément possède lui-même des sous-éléments, il se trouve à droite
une flèche — cela vous permet de faire défiler un niveau vers le bas sans tourner la page.
. 

Occasions typiques : « Liens supplémentaires » à côté d’un article, un
Aperçu du sujet sur une page d’entrée, une table des matières pour un
Zone avec de nombreuses sous-pages. 

## Ce que voient les lecteurs

- En haut, le **titre** — le titre enregistré ou, sans entrée, le titre
  du point de départ. 
- Sous les **sous-éléments** du point de départ, dans l’ordre du menu. 
- Cliquer sur un **titre** ouvre la page elle-même. 
- Cliquer sur la **flèche** à droite fera défiler jusqu’aux sous-éléments de cette flèche
  entrée. En haut, il y a alors une flèche à gauche avec le titre du niveau ; a
  Cliquez dessus pour revenir en arrière. 
- Sur le **téléphone**, un balayage vers la droite fait aussi défiler en arrière. 

Un dossier qui ne contient que d’autres entrées et qui n’a pas sa propre page, 
Ça fait défiler en cliquant sur toute la ligne. 

## Important à savoir

- Le widget **ne copie rien**. Il lit le menu à chaque fois qu’il est appelé : 
  Si le menu change, la navigation aussi. 
- **Les permissions resteront.** Chaque personne ne verra que le
  Des plats qu’elle voit aussi dans le menu de l’application. 
- Les éléments du menu réglés sur **"Non visibles"** dans le menu afficheront le
  La navigation non plus. 
- Les **titres** des éléments du menu apparaissent dans la langue de la personne qui lit, 
  Comme dans le menu de l’application. 

## Ce que vous voyez dans l’éditeur CMS

Dans l’éditeur, le widget apparaît tel qu’il apparaît sur la page publiée et
On peut également y parcourir. Cliquer sur un titre laisse
L’éditeur — il vaut mieux utiliser l’aperçu pour l’essayer.
