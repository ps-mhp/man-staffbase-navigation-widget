# Ustawienia

| Miejsce akcji | Opis |
| --- | --- |
| Punkt startowy w menu | Pozycja menu, której podelementy pokazuje nawigacja. Pole wymagane. Wybierz **Wybierz punkt początkowy ...** z listy — menu pokazuje jako wcięte drzewo, tylko elementy menu z podpozycjami. Elementy menu ukryte w menu mają dodatek "(ukryty w menu)". Jeśli element menu jest nieobecny na liście, wybierz **Wprowadź inny ID menu ...** i wstaw adres jego strony lub 24-cyfrowy ID. |
| Nagłówek | Stoi powyżej pierwszego poziomu. Opcjonalnie; tytuł punktu startowego wydaje się pusty. Przetłumaczone podczas tłumaczenia strony. |

Kolejność, tytuł i widoczność wpisów pochodzą z menu aplikacji
i są tam utrzymywane nie, a nie w widżecie.
