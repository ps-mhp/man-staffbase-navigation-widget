# Definições

| Definição | Descrição |
| --- | --- |
| Ponto de partida no menu | O item do menu que a barra à esquerda apresenta; à direita deste encontram-se os seus subitens. Campo obrigatório. Selecione a opção **Selecionar ponto inicial …** da lista — esta apresenta o menu como uma árvore indentada, apenas com opções de menu que tenham subopções. As opções de menu ocultas no menu têm a indicação «(oculto no menu)». Se o item do menu não constar da lista, selecione **Introduzir outro ID do menu…** e insira o endereço da respetiva página ou o ID de 24 dígitos. |

A ordem, o título e a visibilidade das entradas provêm do menu da aplicação
e são geridos nesse local, não no widget.
