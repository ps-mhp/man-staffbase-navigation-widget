# Configurações

| Cenário | Descrição |
| --- | --- |
| Ponto de partida no menu | O item do menu cujos subitens na navegação mostram. Campo obrigatório. Selecione **Selecione ponto inicial ...** da lista — ele mostra o menu como uma árvore recuada, apenas itens do menu com subitens. Itens do menu ocultos no menu têm a adição "(oculto no menu)". Se o item do menu estiver faltando na lista, selecione **Insira outro ID do menu ...** e insira o endereço da página ou o ID de 24 dígitos. |
| Título | Fica acima do primeiro nível. Opcional; o título do ponto de partida aparece vazio. Traduzido ao traduzir a página. |

A ordem, o título e a visibilidade das entradas vêm do menu do aplicativo
e são mantidos lá, não no widget.
