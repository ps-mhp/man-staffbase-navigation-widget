# Passo a passo

## Inserir navegação

1. Verifique o menu do aplicativo para ver qual item contém as páginas desejadas como
   Subitens. A navegação sempre mostra os subitens **um** 
   item do menu; então as páginas já devem estar penduradas abaixo dele no menu. 
2. Abra a página para edição e anexe o widget **Navegação** ao
   , por exemplo, em uma coluna estreita ao lado do texto. 
3. Nas configurações sob **ponto inicial no menu** a lista
   **Selecione ponto de partida...** aberto. Ele mostra o menu como um recuado
   árvore; apenas itens do menu que possuem subitens são oferecidos. 
4. Selecione o item do menu cujos subitens devem aparecer. 
5. Opcionalmente, insira seu próprio título sob **Título**, por exemplo, 
   "Mais links". O título do ponto de partida permanece vazio. 
6. Salvar e conferir na prévia: Clicar no título abre a página, 
   A seta rola um nível abaixo. 

Se o item do menu não estiver na lista: 

1. Abra a página do item do menu na Base de Funcionários e insira o **endereço completo** 
   Da barra de endereços. 
2. Na lista, selecione **Digitar ID de menu diferente...**. 
3. Cole o endereço no campo. O widget lê o próprio ID
   . 

## Muda ponto de partida ou rumo

1. Abra as configurações do widget. 
2. Sob **Item Iniciar no menu**, selecione outro item do menu ou abaixo
   **Cabeçalho** muda o texto. 
3. Salvar. A navegação então começará novamente no primeiro nível. 

## Adicionar, remover ou reordenar entradas

Isso não é feito no widget, mas no **menu** do app: 

1. Abra o gerenciamento de menus na Staffbase. 
2. Arrastar, remover ou reordenar páginas abaixo do ponto inicial. 
3. Recarregue a página com a navegação — a mudança será visível imediatamente. 

## Quando algo não funciona

1. Se aparecer "O menu não pôde ser carregado", clique
   **Tente novamente**. Se isso não ajudar, verifique se o ponto de partida é
   ainda existe no menu e, se necessário, selecione novamente. 
2. Se uma entrada estiver faltando, verifique o menu para ver se está configurada como "Não visível" ou
   se a pessoa que lê pode ver.
