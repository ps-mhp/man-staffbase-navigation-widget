# Settings

| Setting | Description |
| --- | --- |
| Starting point in the menu | The menu item whose sub-items the navigation shows. Required field. Select **Select starting point ...** from the list — it shows the menu as an indented tree, only menu items with sub-items. Menu items hidden in the menu have the addition "(hidden in the menu)". If the menu item is missing from the list, select **Enter another menu ID ...** and insert the address of its page or the 24-digit ID. |
| Heading | Stands above the first level. Optional; the title of the starting point appears empty. Translated when translating the page. |

The order, title and visibility of the entries come from the app's menu
and are maintained there, not in the widget.
