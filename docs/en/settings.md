# Settings

| Setting | Description |
| --- | --- |
| Start Point in Menu | The menu item displayed on the left side of the bar; its subitems appear to the right of it. Required field. Select from the **Select Start Point …** list—it displays the menu as an indented tree, showing only menu items with subitems. Menu items hidden in the menu are marked with the suffix “(hidden in the menu).” If the menu item is missing from the list, select **Enter Another Menu ID…** and enter the address of its page or the 24-digit ID. |

The order, titles, and visibility of the entries come from the app’s menu
and are managed there, not in the widget.
