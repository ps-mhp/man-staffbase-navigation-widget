# Step by Step

The starting point is selected in the **Select Starting Point** window. It opens
automatically as soon as the widget's settings dialog appears; to close it,
click the **Select Starting Point** button again.

On the left is the app's menu in a tree view, with a search field above it. In the center
are the selected starting point and the bar showing how it will look.

## Insert Navigation

1. Check the app’s menu to see which menu item contains the desired pages as
   subitems. The navigation always displays the subitems of **one**
   menu item; the pages must therefore already be listed under that menu item.
2. Open the page for editing and place the **Navigation** widget at the
   desired location, preferably across the full width—the bar
   needs space for the items next to each other.
3. In the window on the left, under **Start Point in Menu**, click the menu item
   whose subitems you want to display. The arrow next to a folder expands
   it; the search field above finds a menu item by its title.
   Only menu items with subitems can be selected.
4. At the top, under **Desktop**, **Tablet**, and **Mobile**, check the bar for
   device width.
5. Click **Apply** and then save the page. On the
   page: Clicking the title opens the page; the arrow next to it opens the
   subitems as a dropdown.

If the menu item isn’t in the tree:

1. Open the menu item’s page in Staffbase and copy the **full address**
   from the address bar.
2. In the window at the bottom left, click **Enter ID or Address**.
3. Paste the address into the field and click **Set as Starting Point**.
   The widget will automatically retrieve the ID. The starting point will then appear
   at the very top of the tree.

## Change Starting Point

1. Open the widget’s settings—the **Select Start Point** window
   will open with the current start point highlighted.
2. Click a different menu item on the left.
3. Click **Apply** and save. The bar will then display the new
   start point and its subitems.

## Add, Remove, or Reorder Entries

This is not done in the widget, but in the app’s **Menu**:

1. Open the menu management in Staffbase.
2. Drag pages under the starting point, remove them, or reorder them.
3. Reload the page with the navigation—the change will be visible immediately.

## If something isn’t working

1. If the menu doesn’t load in the window, click **Try Again**. If that
   doesn’t help, enter the root menu item via **Enter ID or Address**.
2. If the message “The menu could not be loaded” appears on the page,
   click **Try Again**—in the bar or in a dropdown menu. If
   that doesn’t help, check whether the starting point still exists in the menu and,
   if necessary, select a new one.
3. If an entry is missing, check in the menu to see if it’s set to “Not visible” or
   if the user is authorized to view it.
