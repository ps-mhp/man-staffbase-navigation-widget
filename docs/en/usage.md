# Step by step

## Insert navigation

1. Check the app's menu to see which menu item contains the desired pages as
   sub-items. The navigation always shows the sub-items **one** 
   menu item; so the pages must already be hanging below it in the menu. 
2. Open the page for editing and attach the **Navigation** widget to the
   , e.g. in a narrow column next to the text. 
3. In the settings under **Start point in the menu** the list
   **Select starting point...** open. It shows the menu as an indented
   tree; only menu items that have sub-items are offered. 
4. Select the menu item whose sub-items should appear. 
5. Optionally, enter your own title under **Heading**, e.g. 
   "Further links". The title of the starting point remains empty. 
6. Save and check in preview: Clicking on the title opens the page, 
   the arrow scrolls one level lower. 

If the menu item is not in the list: 

1. Open the page of the menu item in Staffbase and enter the **complete address** 
   from the address bar. 
2. In the list select **Enter different menu ID...**. 
3. Paste the address into the field. The widget reads the ID itself
   . 

## Change starting point or heading

1. Open the widget's settings. 
2. Under **Start item in the menu** select another menu item or under
   **Heading** change the text. 
3. Save. Navigation will then start again on the first level. 

## Add, remove, or reorder entries

This is not done in the widget, but in the **menu** of the app: 

1. Open the menu management in Staffbase. 
2. Drag, remove, or reorder pages below the starting point. 
3. Reload the page with the navigation — the change will be visible immediately. 

## When something doesn't work

1. If "The menu could not be loaded" appears, click
   **Try again** button. If that doesn't help, check if the starting point is
   still exists in the menu, and if necessary, select it again. 
2. If an entry is missing, check the menu to see if it is set to "Not visible" or
   whether the person reading is allowed to see it.
