# Step by Step

## Insert Navigation

1. Check the app's menu to see which menu item contains the desired pages as
   subitems. The navigation always displays the subitems of **one**
   menu item; therefore, the pages must already be listed under that menu item.
2. Open the page for editing and place the **Navigation** widget at the
   desired location, preferably across the full width—the bar
   needs space for the items next to each other.
3. In the settings under **Start Point in Menu**, open the list
   **Select Start Point …**. It displays the menu as an indented
   tree; only menu items that have subitems are listed.
4. Select the menu item whose subitems should appear.
5. Save and check in the preview: Clicking the title opens the page,
   and the arrow opens the subitems as a dropdown.

If the menu item isn’t in the list:

1. Open the menu item’s page in Staffbase and copy the **full address**
   from the address bar.
2. Select **Enter another menu ID…** from the list.
3. Paste the address into the field. The widget will automatically
   extract the ID.

## Change the starting point

1. Open the widget’s settings.
2. Under **Starting point in the menu**, select a different menu item.
3. Save. The bar will then display the new starting point and its
   subitems.

## Add, Remove, or Reorder Entries

This is not done in the widget, but in the app’s **Menu**:

1. Open the menu management in Staffbase.
2. Drag pages under the starting point, remove them, or reorder them.
3. Reload the page with the navigation—the change will be visible immediately.

## If something isn’t working

1. If “The menu could not be loaded” appears, click
   **Try Again**—in the bar or in a dropdown. If that doesn’t help, check whether the starting point
   still exists in the menu, and select it again if necessary.
2. If an entry is missing, check in the menu to see if it’s set to “Not visible” or
   whether the person viewing it is authorized to see it.
